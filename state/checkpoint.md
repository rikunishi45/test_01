# Checkpoints（チェックポイント）

大きなタスクのチェックポイント状況を記録するファイル。

---

## テンプレート

```markdown
## Checkpoint N — [名前]

**Status:** pending | in-progress | done | blocked
**Phase:** planning | implementation | review
**Deliverable:** [この時点でユーザーが確認・レビューすべきもの]
**Acceptance criteria:** [正しさをどう検証するか]
**Approved by:** [human | self]
**Notes:** [想定外の事項]
```
